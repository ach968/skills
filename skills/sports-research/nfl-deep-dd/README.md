# NFL Deep DD

Reusable skill for comprehensive NFL matchups, player props, sportsbook and prediction-market analysis.

Install from `ach968/skills`, selecting `nfl-deep-dd`. Research outputs are created outside the skill directory under a date-and-matchup slug. Source and progress logs must be preserved.

Core files: `SKILL.md`, `references/methodology.md`, `references/markets.md`, `templates/report.md`, `templates/markets.csv`, `templates/postgame.md` and `scripts/market_math.py`.

Example: “Use nfl-deep-dd for a full Bills–Rams matchup dossier. Evaluate every high-liquidity market, stress-test fair probabilities and preserve executable models, source provenance and Markdown progress.”

## Continuous self-improvement

Every run MUST read `references/self-improvement.md`, write a dated `improvement-log.md`, test or evaluate a meaningful improvement hypothesis, and record an ADOPT/REJECT/PENDING decision. Apply safe validated changes only with write permission; otherwise save a proposed patch and explicitly report that the skill was not modified.
